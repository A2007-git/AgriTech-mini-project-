# AgriTech Mini Project

AgriTech is a smart farming advisory and farmer information hub. The provided project includes a web application, Progressive Web App manifest and service worker, plus Windows desktop launcher files.

## Files
- `index.html` — main application page
- `manifest.json` — PWA metadata
- `sw.js` — service worker for offline caching
- `AgriTechApp.cs` — Windows desktop launcher source
- `AgriTech.exe` — compiled desktop launcher
- `Launch-AgriTech.bat` — Windows launch script
- `Create-Desktop-Shortcut.vbs` — desktop shortcut helper

## Run
Open `index.html` in a modern browser, or use `Launch-AgriTech.bat` on Windows.

> The HTML references additional `css/`, `js/`, and `assets/` folders. Those folders were not included in the files uploaded for this commit, so the full app may require them.
